# Stocksprices_dashboard

Réalisez une application front (Angular ou autre) qui met clairement en avant la programmation réactive avec RXJS : observables, Subject / BehaviorSubject, composition de flux et opérateurs (map, filter, debounceTime, switchMap, combineLatest, etc.).

Le sujet est totalement libre : vous pouvez par exemple consommer une API (publique ou non), afficher des graphiques, ou mettre en place un système de filtres / recherche en temps réel. https://github.com/public-apis/public-apis

L'important est de montrer une vraie logique réactive (état centralisé en RxJS, flux dérivés, Ul qui se met à jour automatiquement)
